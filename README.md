# webpatch — เว็บแปะแพตช์ภาษาไทย

เว็บแจกแพตช์แปลไทยสำหรับเกมย้อนยุค ผู้ใช้เลือกไฟล์เกมต้นฉบับของตัวเอง กดปุ่มเดียว
แล้วได้ไฟล์เกมภาษาไทยกลับไปเล่น

**การแปะทำในเบราว์เซอร์ทั้งหมด ไฟล์เกมของผู้ใช้ไม่เคยถูกส่งขึ้นเซิร์ฟเวอร์**
เว็บนี้แจกเฉพาะไฟล์แพตช์ (ดู `docs/adr/0007-rom-never-uploaded.md`)

## เริ่มพัฒนา

```bash
npm install
npm run dev      # เปิด http://localhost:4321
```

ยังไม่ต้องมีบัญชี Supabase ก็รันได้ — เว็บจะใช้ข้อมูลตัวอย่างใน `src/lib/seed-games.js`
และขึ้นป้าย "โหมดตัวอย่าง" บอกไว้

## ทดสอบ

```bash
npm test         # ตัวแปะแพตช์ + ตัวกรองที่อยู่ไฟล์ (30 ข้อ)
npm run test:e2e # หน้าเว็บจริงในเบราว์เซอร์ ต้องรัน npm run dev ค้างไว้ก่อน
```

`npm test` เทียบผลลัพธ์ของตัวแปะแพตช์กับไฟล์ที่เขียนด้วยมือทีละไบต์ตาม spec
ส่วน `test:e2e` ไล่ตั้งแต่เลือกเกม เลือกไฟล์ ตรวจ SHA1 แปะ จนดาวน์โหลด
แล้วเทียบว่าไฟล์ที่ได้ตรงทุกไบต์

## โครงสร้าง

| ที่อยู่ | ทำอะไร |
|---|---|
| `src/patcher/` | ตัวแปะแพตช์ `.ips` `.bps` `.ppf` — หัวใจของเว็บ ทำงานในเบราว์เซอร์ |
| `src/pages/` | หน้าเว็บ |
| `src/pages/api/patch-file/` | ตัวกลางดึงแพตช์จาก GitHub Releases มาส่งต่อพร้อม CORS |
| `src/lib/` | ชั้นข้อมูล (Supabase + ข้อมูลตัวอย่างสำรอง) และตรรกะตรวจฟอร์ม |
| `src/pages/admin/` | หน้าจัดการเกม — เขียนข้อมูลตรงเข้า Supabase สิทธิ์คุมด้วย RLS |
| `supabase/migrations/` | สคีมาและกฎการเข้าถึงฐานข้อมูล |
| `docs/` | เอกสารออกแบบ บันทึกการตัดสินใจ (ADR) และคำศัพท์ |

## สถาปัตยกรรม

```
โค้ด ────────► GitHub ──push──► deploy อัตโนมัติ
หน้าเว็บ+API ► Astro บน Cloudflare Pages
ข้อมูล+login ► Supabase
ไฟล์แพตช์ ───► GitHub Releases ──ผ่านตัวกลาง──► เบราว์เซอร์ผู้ใช้
```

ทุกส่วนอยู่ในโควต้าฟรีและไม่ต้องผูกบัตรเครดิต
เหตุผลของแต่ละข้ออยู่ใน `docs/adr/`

## สถานะตอนนี้

เสร็จแล้ว: หน้าแรก · หน้าแปะแพตช์ · หน้ากำลังทำอยู่ · ตัวแปะทั้ง 3 รูปแบบ ·
ตัวกลาง CORS · เครื่องมือหาค่า SHA1 · หน้า Admin (เพิ่ม/แก้/ลบเกม)

ยังไม่ได้ทำ: ฟอร์มแจ้งบั๊ก · อัปไฟล์แพตช์จากในฟอร์ม Admin (ยังต้องอัปที่ GitHub เองแล้ววางลิงก์)

การตั้งค่าครั้งแรกดู [`docs/setup.md`](docs/setup.md) · เปิดใช้หน้า Admin ดู
[`docs/admin-setup.md`](docs/admin-setup.md)

## ตั้งค่าตอน deploy

คัดลอก `.env.example` เป็น `.env` แล้วใส่ค่าจาก Supabase
บน Cloudflare Pages ให้ใส่ค่าเดียวกันในหน้าตั้งค่า environment variables ของโปรเจกต์
