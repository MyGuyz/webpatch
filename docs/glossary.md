# Glossary — คำศัพท์ประจำโปรเจกต์ webpatch

เอกสารนี้กำหนดว่าแต่ละคำ "แปลว่าอะไร" ในโปรเจกต์นี้ เพื่อให้ทุกคน (และโค้ด) ใช้คำเดียวกันหมายถึงสิ่งเดียวกัน

---

## คำหลักของโดเมน

### แพตช์ (Patch)
ไฟล์ส่วนต่างที่เอาไปทับไฟล์เกมต้นฉบับแล้วได้เกมภาษาไทย — **เป็นสิ่งเดียวที่เว็บนี้แจก**

ในโค้ดใช้ `patch` เสมอ ห้ามใช้คำว่า "ไฟล์เกม" ปนกับคำนี้ เพราะแพตช์ไม่ใช่เกม เล่นเองไม่ได้

### ไฟล์เกมต้นฉบับ (Source ROM / Source ISO)
ไฟล์เกมที่ผู้ใช้ต้องหามาเอง เว็บนี้ไม่แจกและไม่รับอัปโหลด (ดู ADR-007)

ในโค้ดใช้ `source` หรือ `sourceFile` — **ห้ามใช้คำว่า `upload`** กับตัวแปรที่เกี่ยวกับไฟล์นี้ เพราะจะทำให้เข้าใจผิดว่าไฟล์ถูกส่งขึ้นเซิร์ฟเวอร์

### แปะแพตช์ (Apply)
การเอาแพตช์ทับไฟล์ต้นฉบับจนได้ไฟล์เกมภาษาไทย **ทำในเบราว์เซอร์ของผู้ใช้เท่านั้น**

ในโค้ดใช้ `applyPatch(source, patch) → result`

### ไฟล์ผลลัพธ์ (Patched File)
ไฟล์เกมภาษาไทยที่ได้หลังแปะเสร็จ เกิดขึ้นในเครื่องผู้ใช้และถูกเซฟลงเครื่องโดยตรง ไม่เคยผ่านเซิร์ฟเวอร์เรา

---

## คำที่เกี่ยวกับการตรวจสอบ

### SHA1 ต้นฉบับ (Source SHA1)
ลายนิ้วมือของไฟล์เกม**รุ่นที่แพตช์ตัวนี้รองรับ** ใช้ตรวจก่อนแปะว่าผู้ใช้เอาไฟล์ถูกรุ่นมาหรือเปล่า

ถ้าไม่ตรง **ต้องไม่ยอมแปะให้** เพราะจะได้ไฟล์เสียโดยที่ผู้ใช้ไม่รู้ตัว

### สเปกไฟล์ต้นฉบับ (Source Spec)
คำอธิบายรุ่นไฟล์ที่รองรับแบบอ่านออกด้วยตา เช่น `Harvest Moon - Back to Nature (USA) [SLUS-01115] .bin (MODE2/2352)` ใช้บอกผู้ใช้ ส่วน SHA1 ใช้ให้เครื่องตรวจ

### รูปแบบแพตช์ (Patch Format)
หนึ่งใน `.ips` / `.bps` / `.ppf` (ดู ADR-006) แต่ละแบบมีตัวแปะของตัวเองใน `src/patcher/`

---

## คำที่เกี่ยวกับสถานะงาน

### ขั้นความคืบหน้า (Progress Stage)
สถานะงานแปล 5 ขั้น ใช้บนหน้า "กำลังทำอยู่":

1. แกะรอม
2. ดึงคำแปล
3. แปลแล้ว
4. ฝังคำแปล
5. ตรวจสอบบัค

เกมที่ผ่านครบ 5 ขั้นจะย้ายไปอยู่หน้าแปะแพตช์

### สถานะเกม (Game Status)
- **พร้อมให้ Patch** — แปะได้แล้ว โผล่บนหน้าแปะแพตช์
- **กำลังทำอยู่** — ยังไม่เสร็จ โผล่บนหน้า roadmap พร้อมแถบความคืบหน้า
- **BETA** — แปลเสร็จและปล่อยให้เล่นแล้ว แต่ยังตรวจไม่ทั่ว อาจเจอบั๊ก

### เวอร์ชันแพตช์ (Patch Version)
เลขเวอร์ชันของแพตช์แต่ละเกม เช่น `V1.5` ใช้คู่กับ changelog และเป็นตัวบอกผู้ใช้ว่าควรโหลดใหม่หรือยัง

---

## คำที่เกี่ยวกับระบบ

### ตัวกลาง (Patch Proxy)
Astro API route ที่ดึงไฟล์แพตช์จาก GitHub Releases มาส่งต่อให้เบราว์เซอร์พร้อมติด CORS header
มีอยู่เพราะ GitHub Releases ไม่ส่ง CORS มาเอง (ดู ADR-004)

### หน้าจัดการ (Admin)
หน้าเว็บที่ต้อง login ก่อนเข้า ใช้เพิ่ม/แก้/ลบเกม อัปแพตช์ และดูรายงานบั๊ก

### รายงานบั๊ก (Bug Report)
สิ่งที่ผู้เล่นส่งเข้ามาผ่านหน้าแจ้งบั๊ก เก็บใน Supabase เป็นข้อมูลส่วนตัว ไม่เปิดสาธารณะ (ดู ADR-008)

---

## คำที่ห้ามใช้สับสนกัน

| อย่าเขียนว่า | ให้เขียนว่า | เพราะ |
|---|---|---|
| "อัปโหลดเกม" | "เลือกไฟล์เกม" | ไฟล์เกมไม่เคยถูกอัปโหลด (ADR-007) — เขียนผิดคำทำให้ผู้ใช้เข้าใจผิดเรื่องความเป็นส่วนตัวและกฎหมาย |
| "โหลดเกมภาษาไทย" | "โหลดแพตช์ภาษาไทย" | เว็บนี้ไม่แจกเกม แจกแพตช์ |
| "ROM" (ในข้อความที่ผู้ใช้เห็น) | "ไฟล์เกม" / "แผ่นเกม" | คนเล่นทั่วไปไม่รู้จักคำว่า ROM |
