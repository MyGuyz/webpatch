# เปิดใช้หน้าจัดการเกม (Admin)

ทำครั้งเดียว ประมาณ 5 นาที **ไม่ต้องตั้งค่าอะไรใน Cloudflare เพิ่มเลย**

หลังจากนี้การเพิ่ม/แก้/ลบเกมจะทำผ่านฟอร์มบนเว็บ ไม่ต้องเขียน SQL อีก

---

## 1. รันไฟล์ SQL เพิ่มสิทธิ์

Supabase → **SQL Editor** → **New query** → คัดลอกทั้งไฟล์
[`supabase/migrations/0002_admin.sql`](../supabase/migrations/0002_admin.sql) ไปวาง → **Run**

ต้องขึ้น **Success. No rows returned**

## 2. สร้างบัญชีแอดมิน

Supabase → เมนูซ้าย **Authentication** → **Users** → **Add user** → **Create new user**

- **Email** — อีเมลที่จะใช้ล็อกอิน
- **Password** — ตั้งรหัสผ่านที่เดายาก **เก็บไว้ให้ดี**
- ติ๊ก **Auto Confirm User** (ไม่งั้นต้องไปกดยืนยันในอีเมลก่อน)

กด **Create user** แล้ว **คัดลอก User UID** ที่ได้ (สายอักษรยาวๆ มีขีดกลาง)

## 3. ให้สิทธิ์แอดมินกับบัญชีนั้น

การมีบัญชีเฉยๆ **ยังทำอะไรไม่ได้** ต้องระบุตัวว่าเป็นแอดมินก่อน

SQL Editor → วางอันนี้ (แทน UID ที่คัดลอกมาจากข้อ 2):

```sql
insert into admins (user_id, note)
values ('วาง-User-UID-ตรงนี้', 'เจ้าของเว็บ');
```

> ออกแบบให้ต้องระบุเป็นรายคนแบบนี้ เพราะถ้าให้สิทธิ์กับ "ใครก็ตามที่ล็อกอินแล้ว"
> วันไหนเผลอเปิดให้สมัครสมาชิกเองได้ คนที่สมัครเข้ามาจะกลายเป็นแอดมินทันที

## 4. ลองใช้

เข้า **`/admin`** บนเว็บ → ล็อกอินด้วยอีเมลกับรหัสผ่านจากข้อ 2

ควรเห็นรายการเกมทั้งหมด (รวมถึงเกมที่ยังไม่เผยแพร่)

---

## วิธีเพิ่มเกมใหม่หลังจากนี้

1. อัปไฟล์แพตช์ขึ้น **GitHub Releases** → คลิกขวาที่ไฟล์ → **Copy link address**
2. หา SHA1 ของแผ่นต้นฉบับที่ **`/tools/sha1`**
3. `/admin` → **+ เพิ่มเกมใหม่** → กรอกฟอร์ม → **บันทึก**

ไม่ต้องแตะ SQL อีกเลย

---

## สิ่งที่หน้า Admin ทำได้

| ทำอะไรได้ | หมายเหตุ |
|---|---|
| เพิ่ม / แก้ / ลบเกม | ลบต้องพิมพ์ชื่อย่อยืนยัน เพราะกู้คืนไม่ได้ |
| กดเผยแพร่ / ซ่อนจากเว็บ | ทำจากหน้ารายการได้เลย ไม่ต้องเข้าฟอร์ม |
| เห็นเกมที่ยังไม่เผยแพร่ | ร่างเกมไว้ก่อนแล้วค่อยเผยแพร่ทีหลังได้ |

**ยังทำไม่ได้:** อัปไฟล์แพตช์จากในฟอร์มโดยตรง — ยังต้องอัปที่ GitHub เองก่อนแล้ววางลิงก์
(ทำได้ แต่ต้องสร้าง GitHub token มาใส่ Cloudflare เพิ่ม เลยยังไม่ทำในรอบนี้)
