ASupabase — สร้างฐานข้อมูล

จบช่วงนี้พี่จะได้ค่ามา 2 ตัว เอาไปใช้ต่อในช่วง B

  1. เข้า supabase.com/dashboard แล้วกด New project
  2. Name — ตั้งว่า webpatch
  3. Database Password — กดสุ่มแล้วเก็บไว้ที่ปลอดภัย (คู่มือนี้ไม่ได้ใช้ แต่หายแล้วยุ่งทีหลัง)
  4. Region — เลือก Southeast Asia (Singapore) ใกล้ไทยสุด เว็บจะเร็วกว่า
  5. กด Create new project แล้วรอราว 2 นาที
  1. เมนูซ้าย → SQL Editor → New query
  2. เปิดไฟล์ supabase/migrations/0001_initial_schema.sql ใน repo แล้วคัดลอกทั้งไฟล์
  3. วางลงในช่อง แล้วกด Run
ถูกต้องแล้วถ้าเห็น ข้อความ Success. No rows returned — ไฟล์นี้สร้างตารางอย่างเดียว ไม่ได้ดึงข้อมูลอะไรมา จึงไม่มีผลลัพธ์เป็นตารางออกมา

เมนูซ้าย → Table Editor ต้องเห็นครบ 5 ตาราง:

announcements · bug_reports · changelogs · consoles · games

เปิดตาราง consoles ดู จะมีเครื่องเล่นใส่ไว้ให้แล้ว 5 แถว (Super Famicom, GBA, NDS, PS1, PSP) — จำเลข id ของแต่ละเครื่องไว้ เดี๋ยวได้ใช้ตอน C3

เมนูซ้าย → Project Settings (รูปฟันเฟือง) → API keys

ห้ามหยิบผิดตัว ในหน้าเดียวกันจะมีคีย์ชื่อ service_role อยู่ด้วย — อย่าเอามาใช้เด็ดขาด ตัวนั้นข้ามระบบความปลอดภัยทั้งหมด ถ้าหลุดออกไปคนอื่นลบข้อมูลเราได้เกลี้ยง ตัวที่ต้องใช้คือ anon public เท่านั้น ซึ่งเปิดเผยได้ปลอดภัยเพราะมีกฎในไฟล์ SQL คุมอยู่

BCloudflare — เอาเว็บขึ้นออนไลน์

จบช่วงนี้จะได้ ลิงก์เว็บจริง ที่ใครก็เปิดได้

  1. เข้า dash.cloudflare.com → เมนูซ้าย Workers & Pages
  2. กด Create → แท็บ Import a repository
  3. กด Connect GitHub แล้วอนุญาตให้เห็น repo MyGuyz/webpatch
  4. เลือก webpatch → Begin setup
ช่องใส่อะไร
Project nameตั้งว่า webpatch — ชื่อนี้จะกลายเป็นที่อยู่เว็บ
Production branchmain
Build commandnpm run build
Deploy commandnpx wrangler deploy
ไม่ต้องทำแล้ว ปกติ Astro จะบังคับให้สร้าง KV namespace กับผูก Images binding เพิ่ม ผมปิดสองอย่างนั้นไปแล้วเพราะเว็บเราไม่ได้ใช้ พี่จะไม่เจอขั้นตอนพวกนั้น

ในหน้าเดียวกัน หาหัวข้อ Environment variables หรือ Build variables แล้วเพิ่ม 2 ตัว:

ชื่อตัวแปรค่า
PUBLIC_SUPABASE_URLProject URL จาก A4
PUBLIC_SUPABASE_ANON_KEYanon public key จาก A4
ใส่ช่องไหนก็ได้ Cloudflare มีช่องใส่ตัวแปร 2 ที่ คือตอน build กับตอน เว็บทำงาน (runtime) — เว็บอ่านได้ทั้งสองช่อง ไม่ต้องกังวลว่าจะใส่ผิดที่

แต่ ต้อง deploy ใหม่หลังใส่ค่า ค่าถึงจะมีผล

กด Save and Deploy แล้วรอ 2–4 นาที เสร็จแล้วจะได้ลิงก์หน้าตาแบบ https://webpatch.xxx.workers.dev

ถ้าขึ้นแดงว่า build ไม่ผ่าน ให้กดเข้าไปดู log แล้วแคปหน้าจอมาถามได้

Cตรวจว่าใช้ได้จริง

จบช่วงนี้จะมีเกมแรกให้คนโหลดไปแปะได้จริง

เปิดลิงก์ที่ได้จาก B4 — ต้องไม่มีกล่องเหลืองเขียนว่า "โหมดตัวอย่าง"

  • ยังเห็นกล่องเหลือง → ใส่ตัวแปรผิดช่อง กลับไปทำ B3 แล้ว deploy ใหม่
  • ขึ้น error 500 → ใส่ตัวแปรมาแค่ตัวเดียว หน้าจอจะบอกเองว่าขาดตัวไหน

ไม่ได้พังนะ เพราะฐานข้อมูลยังไม่มีเกมสักเกม ข้อมูลสมมติหายไปแล้วเพราะตอนนี้อ่านจากของจริง — ขั้นถัดไปคือใส่เกมแรก

กลับไป Supabase → Table Editor → ตาราง games → Insert row

ช่องใส่อะไร
console_idเลข id ของเครื่อง ดูจากตาราง consoles (A3)
slugชื่ออังกฤษไม่มีเว้นวรรค เช่น bahamut-lagoon · ห้ามซ้ำเกมอื่น
titleชื่อเกม
statusready ถ้าแพตช์เสร็จ · wip ถ้ายังทำอยู่
patch_urlลิงก์ไฟล์แพตช์ (ได้จาก C4)
patch_formatips / bps / ppf
source_sha1ลากไฟล์เกมต้นฉบับลงหน้า /tools/sha1 บนเว็บ แล้วคัดลอกค่ามาใส่ · เว้นว่างได้ = ไม่ตรวจรุ่น
is_publishedติ๊กให้เป็น true ไม่งั้นเว็บจะไม่แสดง
ระบบกันไว้ให้ เกมที่ status เป็น ready ต้องมี patch_url และ patch_format ครบ ไม่งั้นฐานข้อมูลจะไม่ยอมบันทึก — กันไม่ให้คนกดเข้ามาแล้วเจอหน้าเปล่า

repo → Settings → เลื่อนล่างสุดถึง Danger Zone → Change visibility → Make public

ทำไมต้องเปิด ไฟล์ใน Releases ของ repo ส่วนตัว ต้องล็อกอินถึงโหลดได้ แต่เว็บดึงไฟล์แบบไม่ล็อกอิน ถ้าไม่เปิดสาธารณะ คนกดแปะแล้วจะขึ้น error 404

ตรวจแล้วว่าไม่มีความลับอยู่ใน repo — ไม่มีไฟล์ .env และคีย์ Supabase อยู่ใน Cloudflare ไม่ได้อยู่ในโค้ด
  1. ไปที่ repo บน GitHub → ขวามือหา Releases → Create a new release
  2. Choose a tag → พิมพ์ tag ใหม่ เช่น bahamut-v1.3 → Create new tag
  3. ลากไฟล์แพตช์มาวางในช่อง Attach binaries
  4. กด Publish release
  5. คลิกขวาที่ไฟล์ที่แนบ → Copy link address → เอาไปใส่ patch_url ใน C3

ไฟล์ใหญ่ได้ถึง 2GB และคนโหลดเท่าไหร่ก็ได้ ไม่มีโควต้า

เปิดหน้า แปะแพตช์ บนเว็บ → เลือกเกม → เลือกไฟล์เกมต้นฉบับ → กดแปะ → ดาวน์โหลด

เอาไฟล์ที่ได้ไปเปิดในอีมูเลเตอร์ ถ้าเป็นภาษาไทย — จบครับ เว็บใช้งานได้แล้ว 🎮
