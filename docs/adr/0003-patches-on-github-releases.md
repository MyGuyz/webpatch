# ADR-003 — เก็บไฟล์แพตช์บน GitHub Releases

**สถานะ:** ตกลงแล้ว · 2026-08-20

## บริบท
ไฟล์แพตช์ที่จะแจกมีทั้งเล็กและใหญ่ บางตัว 50–500MB (เกม PS1/PSP) ต้องหาที่เก็บที่ฟรีและรับปริมาณคนโหลดได้

## ปัญหา
คำนวณจากโควต้าฟรีของ Supabase: ที่เก็บ 1GB และข้อมูลขาออกเดือนละ 5GB
→ แพตช์ขนาด 100MB มีคนโหลดแค่ **50 คน ก็หมดโควต้าทั้งเดือน** หลังจากนั้นเว็บดาวน์โหลดไม่ได้จนขึ้นเดือนใหม่

## ทางเลือกที่พิจารณา
| ทางเลือก | เพดานไฟล์ | ข้อมูลขาออก | ต้องผูกบัตร |
|---|---|---|---|
| Supabase Storage | 50MB/ไฟล์ | 5GB/เดือน | ไม่ |
| **GitHub Releases** | **2GB/ไฟล์** | **ไม่จำกัด** | **ไม่** |
| ไฟล์ใน git repo | 100MB/ไฟล์ (แข็ง) | ไม่จำกัด | ไม่ |
| Cloudflare R2 | ไม่จำกัด | ไม่จำกัด | **ต้อง** |

## การตัดสินใจ
เก็บไฟล์แพตช์บน **GitHub Releases** ส่วน Supabase เก็บเฉพาะข้อมูลเกมและรูปภาพ

## เหตุผล
- ฟรีสนิท ไม่ต้องผูกบัตร ตรงตามเงื่อนไขที่ตั้งไว้
- เพดานไฟล์ 2GB ครอบคลุมแพตช์ใหญ่สุดที่จะมี
- คนโหลดเท่าไหร่ก็ได้ ไม่มีโควต้ารายเดือนให้กังวล
- มีระบบเวอร์ชันในตัว (แพตช์ v1.0 → v1.5 เก็บแยกกัน ย้อนกลับได้)
- ยังอยู่บน GitHub ตรงตามความตั้งใจเดิม

## เงื่อนไขที่ค้นพบทีหลัง — repo ต้องเป็นสาธารณะ

พบตอนเอาเกมแรกขึ้นจริง: **ไฟล์ release ของ repo ส่วนตัวต้องล็อกอินถึงโหลดได้**
ทดสอบด้วยวิธีเดียวกันเทียบกัน:

| ทดสอบ | ผล |
|---|---|
| ไฟล์ release ของ repo สาธารณะ (`cli/cli`) | 206 โหลดได้ |
| ไฟล์ release ของ repo ส่วนตัว (`MyGuyz/webpatch` ตอนนั้น) | 404 |

ตัวกลางตาม ADR-004 ดึงไฟล์แบบไม่แนบ credential จึงได้ 404 ตามไปด้วย
ทั้งที่ข้อมูลในฐานข้อมูลถูกต้องทุกอย่าง

**ทางเลือกที่พิจารณา**
- **เปิด repo เป็นสาธารณะ** ← เลือกข้อนี้ ตรวจแล้วว่าไม่มีความลับใน git
  (ไม่มี `.env`, `.env.example` เป็นค่าว่าง) และเว็บนี้ตั้งใจแจกแพตช์ฟรีอยู่แล้ว
  นอกจากนี้โควต้าดาวน์โหลดไม่จำกัดของ GitHub ก็ใช้กับ repo สาธารณะเท่านั้น
- ให้ตัวกลางถือ GitHub token แล้วดึงผ่าน API — ตัดทิ้งเพราะต้องสร้างและหมุน token เพิ่ม
  และทำให้ทุกครั้งที่มีคนโหลดแพตช์ไปกินโควต้า API ซึ่งมีเพดานต่อชั่วโมง

**ข้อความ error ของตัวกลางจึงบอกใบ้กรณีนี้ไว้แล้ว** เมื่อต้นทางตอบ 404

## ผลที่ตามมา
- **เกิดปัญหา CORS ตามมา** ซึ่งแก้ด้วย ADR-004
- **repo ต้องเป็นสาธารณะตลอดไป** ถ้าวันหนึ่งเปลี่ยนกลับเป็นส่วนตัว แพตช์จะโหลดไม่ได้ทันที
- ไฟล์ใน repo ไม่บวม เพราะ release asset ไม่นับเป็นส่วนหนึ่งของประวัติ git
