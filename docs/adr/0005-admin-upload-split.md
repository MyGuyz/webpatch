# ADR-005 — หน้า Admin อัปไฟล์เล็กผ่านฟอร์ม ไฟล์ใหญ่วางลิงก์

**สถานะ:** ตกลงแล้ว · 2026-08-20

## บริบท
เป้าหมายคือ "ฟอร์มเดียวจบ" — กรอกข้อมูลเกม ลากไฟล์แพตช์ใส่ กดบันทึก แล้วระบบจัดการที่เหลือให้เอง

## ปัญหาที่ชนกัน 2 ข้อ
1. การอัปไฟล์ขึ้น GitHub Releases ต้องใช้ GitHub token และ **token ห้ามอยู่ในหน้าเว็บเด็ดขาด** (เปิด devtools ก็เห็น แล้วเอาไปเขียน repo ได้) จึงต้องส่งผ่านตัวกลางที่เก็บ token ไว้ฝั่งเซิร์ฟเวอร์
2. แต่ตัวกลางบน Cloudflare ฟรี **รับข้อมูลขาเข้าได้แค่ 100MB ต่อคำขอ** แพตช์ 500MB จึงอัปไม่ผ่าน

## ทางเลือกที่พิจารณา
- **ล็อกอินด้วย GitHub แล้วให้เบราว์เซอร์อัปตรงเข้า GitHub** — ไม่ติดเพดานและ token เป็นของแอดมินเอง แต่**ยืนยันไม่ได้ว่า `uploads.github.com` เปิด CORS ให้หรือไม่** (สภาพแวดล้อมที่ทดสอบบล็อก `api.github.com` ตอบกลับ 403 ซึ่งเป็นคำตอบของตัวกรองเน็ต ไม่ใช่ของ GitHub) จึงไม่เอามาเป็นทางหลักเพราะยังพิสูจน์ไม่ได้
- **แยกทางตามขนาดไฟล์** ← เลือกข้อนี้

## การตัดสินใจ
- ไฟล์แพตช์ **≤100MB** → ลากใส่ฟอร์มได้เลย ระบบอัปขึ้น GitHub Releases ให้ผ่านตัวกลางที่ถือ token
- ไฟล์ **>100MB** → แอดมินลากขึ้นหน้า release ของ GitHub เอง แล้ววางลิงก์ลงในฟอร์ม

## เหตุผล
- ไม่พนันกับสมมติฐานที่ยังพิสูจน์ไม่ได้
- ไม่มี token รั่วในทุกกรณี
- เพิ่มเกมสัปดาห์ละครั้ง ความไม่สะดวกของเคสไฟล์ใหญ่จึงรับได้ และแพตช์ส่วนใหญ่เล็กกว่า 100MB อยู่แล้ว

## ผลที่ตามมา
- ฟอร์มต้องรับได้ทั้งไฟล์และลิงก์ พร้อมบอกผู้ใช้ให้ชัดว่าเมื่อไหร่ต้องใช้ทางไหน
- GitHub token ต้องเป็นแบบ fine-grained ให้สิทธิ์เขียน release ของ repo นี้เท่านั้น
- ถ้าภายหลังพิสูจน์ได้ว่าอัปตรงจากเบราว์เซอร์ได้จริง ค่อยเปลี่ยนมาใช้แล้วยกเลิกข้อจำกัดนี้
