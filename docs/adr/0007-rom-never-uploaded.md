# ADR-007 — ไฟล์เกมของผู้ใช้ห้ามออกจากเครื่องเด็ดขาด

**สถานะ:** ตกลงแล้ว · 2026-08-20

## บริบท
เว็บนี้ทำให้ผู้ใช้ได้เกมภาษาไทย ซึ่งต้องเอาแพตช์ไปรวมกับไฟล์เกมต้นฉบับ คำถามคือการรวมนั้นเกิดที่ไหน

## การตัดสินใจ
**การแปะแพตช์ทำในเบราว์เซอร์ของผู้ใช้ทั้งหมด** เว็บแจกเฉพาะไฟล์แพตช์ ผู้ใช้ต้องมีไฟล์เกมต้นฉบับของตัวเอง ไฟล์เกมไม่ถูกส่งขึ้นเซิร์ฟเวอร์ในทุกกรณี

## เหตุผล
- **จุดยืนด้านกฎหมาย** — แพตช์แปลเป็นผลงานของผู้แปล แต่ไฟล์เกมต้นฉบับเป็นลิขสิทธิ์ของผู้ผลิต เว็บนี้จึงไม่แตะไฟล์เกมเลย เว็บอ้างอิงทั้งสองแห่งก็ยึดหลักเดียวกันและเขียนบอกไว้เด่นชัด
- **ประหยัดทรัพยากร** — ไม่ต้องรับไฟล์ระดับ GB ขึ้นเซิร์ฟเวอร์ ซึ่งไม่มีทางอยู่ในโควต้าฟรีได้อยู่แล้ว
- **ความเป็นส่วนตัวของผู้ใช้** — ไม่มีไฟล์ของใครค้างบนเซิร์ฟเวอร์เรา

## ผลที่ตามมา
- ต้องเขียนบอกผู้ใช้ให้ชัดและเห็นง่ายบนหน้าแปะแพตช์
- ต้องตรวจ SHA1 ของไฟล์ต้นฉบับก่อนแปะ เพื่อกันคนใช้ไฟล์ผิดรุ่นแล้วได้ไฟล์เสีย
- ประสิทธิภาพขึ้นกับเครื่องผู้ใช้ จึงต้องเตือนเรื่องไฟล์ใหญ่บนมือถือ
