# ADR-008 — รายงานบั๊กเก็บใน Supabase ไม่ใช่ GitHub Issues

**สถานะ:** ตกลงแล้ว · 2026-08-20

## บริบท
ต้องมีช่องทางให้ผู้เล่นแจ้งคำแปลผิด ตัวอักษรเพี้ยน หรือเกมค้าง พร้อมแนบภาพหน้าจอได้

## ทางเลือกที่พิจารณา
| ทางเลือก | ข้อดี | ข้อเสีย |
|---|---|---|
| **Supabase** | ผู้เล่นไม่ต้องมีบัญชีอะไรเลย, รายงานเป็นส่วนตัว, ดูรวมในหน้า Admin ที่มีอยู่แล้ว | ต้องทำหน้ารวมรายงานเอง |
| GitHub Issues | ฟรี มีระบบติดตามงานในตัว | **ผู้แจ้งต้องมีบัญชี GitHub** ซึ่งคนเล่นเกมทั่วไปส่วนใหญ่ไม่มี, บั๊กเปิดเป็นสาธารณะ |

## การตัดสินใจ
เก็บลงตาราง `bug_reports` ใน Supabase และดูรวมในหน้า Admin ภาพหน้าจอเก็บใน Supabase Storage (ไฟล์เล็ก อยู่ในโควต้าสบาย)

## เหตุผล
กลุ่มผู้ใช้เป้าหมายคือคนเล่นเกม ไม่ใช่นักพัฒนา การบังคับให้สมัคร GitHub ก่อนแจ้งบั๊กจะทำให้แทบไม่มีใครแจ้ง ซึ่งขัดกับวัตถุประสงค์ของฟีเจอร์นี้ตั้งแต่ต้น

## ผลที่ตามมา
- ต้องตั้ง Row Level Security ให้คนทั่วไป "แทรกได้ อ่านไม่ได้" เพื่อไม่ให้เห็นรายงานของคนอื่น
- ต้องกันการสแปม (จำกัดขนาดไฟล์แนบและจำนวนครั้งที่ส่งได้)
