# ฟอร์มแจ้งบั๊กบังคับแนบรูปหรือวิดีโออย่างน้อย 1 ไฟล์ จำกัดไฟล์ละ 30MB

ฟอร์มแจ้งบั๊กให้ผู้เล่นเลือกเกม เลือกเวอร์ชันแพตช์ แล้ว**บังคับแนบรูปหรือวิดีโออย่างน้อย 1 ไฟล์**
(อย่างใดอย่างหนึ่งก็ได้ ไม่ต้องมีทั้งคู่) คู่กับรายละเอียดที่พิมพ์ — กันรายงานที่บอกแค่ "บั๊ก" ลอยๆ
ไม่มีหลักฐานให้ตามรอย

การอนุญาตวิดีโอขัดกับสมมติฐานเดิมตอนเลือก Supabase Storage (เก็บไฟล์แนบ) ที่ระบุว่า
"ไฟล์เล็ก อยู่ในโควต้า 1GB สบาย" — วิดีโอหนักกว่ารูปมาก จึง**จำกัดไฟล์แนบแต่ละไฟล์ไม่เกิน 30MB**
(เช็คขนาดฝั่งเบราว์เซอร์ก่อนอัปโหลด ไม่ใช่ตรวจหลังอัปเสร็จ) เพื่อไม่ให้โควต้าฟรีเต็มเร็วกว่าที่วางแผนไว้

**ผลต่อ schema:** ตาราง `bug_reports` เดิมมีแค่คอลัมน์ `image_urls text[]` (migration `0001_initial_schema.sql`)
ต้องเพิ่ม migration ใหม่รองรับไฟล์วิดีโอก่อนสร้างฟอร์มจริง (ตัดสินใจร่วมกับเจ้าของโปรเจกต์ 2026-08-24)
