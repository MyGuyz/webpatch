# ADR-001 — แยกที่โฮสต์ออกจาก GitHub Pages

**สถานะ:** ตกลงแล้ว · 2026-08-20

## บริบท
เดิมตั้งใจโฮสต์บน GitHub Pages เพราะอยากทำงานบน GitHub ทั้งหมด แต่ความต้องการเปลี่ยนไปเมื่อยืนยันว่าต้องมีระบบหลังบ้านจริง สำหรับเพิ่ม/ลบเกมได้สะดวกโดยไม่ต้องแก้ไฟล์ผ่าน git

## ปัญหา
GitHub Pages เสิร์ฟไฟล์นิ่งอย่างเดียว รันโค้ดฝั่งเซิร์ฟเวอร์ไม่ได้ จึงรองรับหน้า Admin ที่ต้องตรวจสิทธิ์และเขียนฐานข้อมูลไม่ได้

## การตัดสินใจ
ย้ายที่โฮสต์ไป **Cloudflare Pages** โดยโค้ดและไฟล์แพตช์ยังอยู่บน GitHub ทั้งหมด และ push แล้ว deploy อัตโนมัติเหมือนเดิม

"ทำงานบน GitHub" กับ "โฮสต์บน GitHub Pages" เป็นคนละเรื่อง — ข้อนี้แลกอย่างหลังเพื่อรักษาอย่างแรกไว้

## เหตุผลที่เลือก Cloudflare Pages
- ฟรี ไม่ต้องผูกบัตรเครดิต (ต่างจาก Cloudflare R2 ที่ต้องผูก)
- เชื่อมกับ GitHub ได้โดยตรง
- รันโค้ดฝั่งเซิร์ฟเวอร์ได้ ซึ่งจำเป็นทั้งกับหน้า Admin และตัวกลาง CORS (ดู ADR-004)
- ไม่จำกัดปริมาณข้อมูลขาออก

## ผลที่ตามมา
- ต้องสมัครบัญชี Cloudflare เพิ่ม 1 บัญชี
- URL เว็บเปลี่ยนจาก `*.github.io` เป็น `*.pages.dev` (ผูกโดเมนตัวเองทีหลังได้)
- ได้ความสามารถรันโค้ดฝั่งเซิร์ฟเวอร์ ซึ่งเป็นเงื่อนไขจำเป็นของ ADR-004 และ ADR-005
